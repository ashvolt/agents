Is this AI lettering real text? A person and the system, side by side

On AI-generated stickers the checker blocks many files for text that measures under the print minimum. Much of that lettering is Stable Diffusion's garbled writing. We asked a person to judge each flagged region, twice for some, to see whether a rule could let "garbled" lettering through. It could not: the judgement did not repeat, so no rule was built and the system keeps blocking. These labels tested a rule; the system did not learn from them.

How the two sides compare

The system blocked every one of these files for text too small. Each file falls into one of these groups by what the person answered.

System confidence here is a measurement, not a probability: how far the text is under the minimum, as a share of it and in pixels at print resolution. Person confidence is consistency: whether controls were answered right and repeats answered the same.
